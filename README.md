# GovFlow Intelligence v0.2 — Working Founder Demo

Open `web/index.html` in a modern browser. No server is required for this founder-demo build.

## What works
- Control Tower KPIs over 1,000 synthetic government transactions.
- Department risk visualization.
- Bottleneck Radar.
- Highest-risk active transaction queue.
- Interactive What-If Simulator for transaction-volume and reviewer-capacity changes.

## Important
The risk engine and simulator in v0.2 are transparent demo heuristics, not production ML models.
All included operational data is synthetic.
No employer/client source code, schema, documentation, credentials, screenshots, or data is included.
