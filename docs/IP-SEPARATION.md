# IP Separation / Clean-Room Log

Project: GovFlow Intelligence
Founder Demo baseline date: 2026-08-25

## Rules
- Build only on personal/project-controlled systems and accounts.
- Use synthetic, public, or properly licensed data only.
- Do not copy source code, SQL, database schemas, API specifications, internal documents, screenshots, credentials, or customer data from any employer/client environment.
- Do not encode confidential customer-specific workflows into the core product.
- Keep customer integrations behind generic adapters.
- Record major design decisions and repository commits.
- Review employment/IP/conflict terms before commercial engagement with an employer's current customer.
